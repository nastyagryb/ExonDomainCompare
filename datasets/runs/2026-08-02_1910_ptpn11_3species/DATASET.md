# PTPN11 — Homo sapiens, Mus musculus, Rattus norvegicus

This bundled read-only dataset demonstrates the generic exploratory isoform workflow. Protein-difference Candidates are exploratory evidence, not validated splicing events. The dataset must not be presented as validated FGFR2-like event biology.

Logs, SSH/Slurm state, user names, cluster paths, raw NCBI caches and private machine paths are intentionally omitted.
