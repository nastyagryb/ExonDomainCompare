# Data notes

## `data/framework_snapshot/cohort`

The selected FGFR2 models and their review status. `final_pre_interpro_truth_table.tsv` is the framework closure table. `fgfr2_post_rescue_final_truth_table.tsv` is the compact table used by the downstream analysis scripts. The primary FASTA contains the protein sequences selected for the framework run.

## `data/framework_snapshot/exon_protein_mapping`

Tables that connect transcript/CDS annotation to amino-acid coordinates. The coordinate audit files record cases that required reconstruction or consistency checks. These files establish the coordinate system used before domain boundaries are compared.

## `data/framework_snapshot/alignments`

The combined cassette MSA is the input used for JSD, topology and leave-one-clade-out analyses. The full-length MSA and its QC tables check the selected primary proteins in a wider sequence context. Separate IIIb and IIIc alignments are retained for inspection. No active ancestral reconstruction is derived from this alignment.

## `data/framework_snapshot/protein_annotations`

Normalized InterPro intervals, pyTMHMM segments, the joined exon–domain architecture and domain QC. `interpro_ensemble_coordinate_support_calls.tsv` is the analysis-ready table used for caller-bias and threshold analyses.

## `data/framework_snapshot/comparative`

Machine-readable source tables for the comparative application views: species inventory, MSA coordinates, exon/domain intervals, boundary groups, pairwise identity, isoform diversity and synteny.

## `results/00_framework_outputs`

Exact SVG and TSV exports from the website’s comparative figure gallery, plus selected indices used by the frontend. These files document what the application exposed for the frozen FGFR2 run. They are exploratory views and QC outputs unless a later analysis tests the same question formally.

## `data/external`

Inputs that were not generated by the framework itself: PDB structures, the curated human cassette reference and IQ-TREE outputs used by the downstream analyses.

## `results/01`–`08`

Frozen result tables, summaries and SVG figures. The directory names follow the order in `METHODS.md` and `RESULTS.md`. Reproduction targets write to `results/reproduced` instead of changing these reference files.
